# Tugas Projek Kelompok Kelas 12A
## Pengembangan Sistem Informasi Sederhana dengan OOP & PDO

**Kelompok 3 — Sistem Pengaduan Fasilitas**
* **Radzi** - Ketua
* **Mu'adz** - Anggota
* **Akhtaar** - Anggota

## Deskripsi
Tugas ini bertujuan untuk membuat sistem pencatatan dan pengelolaan laporan kerusakan atau masalah fasilitas (Contoh: AC rusak, lampu mati, toilet bermasalah, meja rusak, dan sebagainya).

## Fitur Minimal
* CRUD data fasilitas
* Membuat laporan pengaduan
* Menampilkan daftar pengaduan
* Mengubah status pengaduan
* Menambahkan keterangan/tindak lanjut
* Menghapus data pengaduan
* Validasi input

## Contoh Alur Sistem
Fasilitas ➔ Lapor Masalah ➔ Diproses ➔ Ditangani ➔ Selesai

1. **Fasilitas:** Pengguna melihat daftar fasilitas yang ada.
2. **Lapor Masalah:** Pengguna memilih fasilitas yang bermasalah, mengisi detail kerusakan, lalu mengirim aduan.
3. **Diproses:** Admin memeriksa laporan yang masuk.
4. **Ditangani:** Petugas melakukan perbaikan di lapangan.
5. **Selesai:** Perbaikan selesai dan admin menginput keterangan tindak lanjut.

## Lingkungan Pengembangan & Teknologi
* **Bahasa Pemrograman:** PHP (Object-Oriented Programming / OOP)
* **Database Driver:** PDO (PHP Data Objects)
* **Database:** MySQL
* **Local Server:** Laragon
